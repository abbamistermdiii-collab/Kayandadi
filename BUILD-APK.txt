SHAFIN BATSA - ANDROID APP (WebView + in-app browser)

You do NOT need Android Studio. Build the APK for free with GitHub:

1. Create a free account at github.com and make a new repository (name: shafinbatsa-app).
2. Upload the contents of this folder to it (Add file > Upload files).
   IMPORTANT: the hidden ".github/workflows/build.yml" file must be included.
   If it did not upload: Add file > Create new file, type  .github/workflows/build.yml
   and paste the build.yml text from this folder.
3. Open the "Actions" tab. "Build APK" runs automatically (or press "Run workflow"). Wait about 5 minutes.
4. Open the finished run, scroll to "Artifacts", download "ShafinBatsa-apk" (a zip), unzip it.
5. Send app-debug.apk to your phone and install it (allow "Install unknown apps" when asked).

UPDATING: change files in the repo (for example app/src/main/assets/index.html), the build runs again, download the new APK.

OPTIONAL - instant updates without rebuilding:
In app/build.gradle change START_URL to your Netlify link, e.g.  "\"https://YOUR-SITE.netlify.app/\""
